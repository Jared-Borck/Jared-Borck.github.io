Professional Self-Assessment

My development through the computer science program and the experience behind this portfolio.

Completing the Computer Science program has helped me develop from someone interested in technology into someone who can design, build, test, and improve complete software systems. Throughout the program, I worked with several programming languages, frameworks, databases, and development environments. That experience strengthened my interest in backend and full-stack software development and showed me how different parts of a software system work together.

Software engineering has been one of my strongest areas of growth. Projects such as Travlr Getaways gave me experience with Angular, Node.js, Express, REST APIs, and MongoDB. I also worked with OpenGL graphics, Android application development, and Unity using C#. These projects reinforced the importance of maintainable code, testing, documentation, and understanding an existing system before making changes.

My algorithms and data structures work taught me to think about the needs of a problem before choosing a solution. In CS 370, I worked with deep Q-learning for the CartPole problem. In my capstone, I implemented weighted scoring, review grouping with a Map, merge sort for a complete trip ranking, and a min-heap for selecting the top results. I tested those algorithms and considered the trade-offs between their time and space complexity.

Database courses and projects gave me experience with SQL and MongoDB. I used those skills in Travlr Getaways to strengthen schema validation, apply uniqueness constraints, build compound indexes, and create MongoDB aggregation pipelines. I also used query analysis to verify index use. This helped me understand how database design influences application efficiency, reliability, and data integrity.

Security has become an important consideration in my software development process. I worked with JSON Web Token authentication, customer and administrator roles, backend authorization checks, review ownership, and validation. Those changes demonstrated why security should be enforced throughout an application rather than depending on what the interface allows a user to see.

Communication and collaboration have also shaped how I work. My CS 499 code review and written narratives required me to explain technical decisions clearly to an audience. Outside coursework, my team-lead experience has involved coordinating people, communicating expectations, adapting to changing priorities, and taking responsibility for shared results. These skills are important when developing software with colleagues and stakeholders.

My ePortfolio brings this work together. The original Travlr Getaways application and its three enhanced versions show how I evaluated an existing codebase, improved its software architecture and security, added algorithms and data structures, and strengthened the database layer. I plan to use this foundation to begin a career in software development and keep improving through professional experience and personal projects.

CS 499 · Computer Science Capstone

One application, three engineering improvements

Travlr Getaways began as a CS 465 full-stack application. The capstone demonstrates how I improved its functionality, algorithms, and data layer in stages while preserving the work completed before each enhancement.

01 · Software Design & Engineering

Reviews and authorization

Added customer reviews, role-based permissions, ownership checks, JWT authentication changes, and frontend integration.

02 · Algorithms & Data Structures

Ranking and Top-K selection

Built weighted trip rankings with a Map, custom merge sort, and a min-heap. Added automated tests for the core algorithms.

03 · Databases

Integrity and aggregation

Added compound indexes, database-level uniqueness rules, stronger validation, and MongoDB aggregation for review statistics.
